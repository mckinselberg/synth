# Synth

A browser-based polyphonic synthesizer built with React and [Tone.js](https://tonejs.github.io/). Play notes using your computer keyboard or mouse. The app supports real-time audio synthesis, with plans for effects, presets, and more.

---

## Features

- Virtual piano keyboard (playable with mouse or computer keyboard)
- Polyphonic sound (multiple notes at once)
- Pauses audio when tab is inactive (prevents stuck notes)
- Modular design for future effects and controls

## Planned Improvements

- Accessible keyboard navigation and ARIA support
- Responsive design for mobile/touch devices
- Integrate real-time effects and sound-shaping controls
- Record/playback user performances
- Preset management (save/load sounds)
- Add tests and improve documentation

## Getting Started

1. **Clone the repository:**

   ```sh
   git clone https://github.com/mckinselberg/synth.git
   cd synth
   ```

2. **Install dependencies:**

   ```sh
   npm install
   ```

3. **Start the development server:**

   ```sh
   npm start
   ```

4. **Open your browser and play!**

## Usage

- Play notes with your keyboard (A, S, D, F, ... etc.).
- Click on the virtual keyboard with your mouse or tap on touch devices.
